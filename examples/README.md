# Examples

運用ログの記入例です。**すべて架空データ**であり、実在の作業・費用を示すものではありません。
テスト(`tests/`)のフィクスチャとしても使用されます。

- `ai-usage/2026-07.yaml` — AI利用ログの例(スキーマ: `schemas/ai-usage-log.schema.json`)
- `effort/2026-07.yaml` — 作業ログの例(スキーマ: `schemas/work-log.schema.json`)
- `effort/estimates.yaml` — 見積の例(スキーマ: `schemas/issue-estimate.schema.json`)

実運用のログは `reports/` 配下に同じ形式で記録してください。
