# 品質管理(Quality Management)

> 本書は ISO 9001 の考え方を参考にした実用的な運用ルールであり、
> 本リポジトリが ISO 認証を取得している、または規格へ完全適合していることを意味しません。

## 目的

学習コンテンツと生成基盤の品質を、作成 → レビュー → 承認 → 改善のサイクルで維持する。

## 品質方針

1. 要求事項は Issue の Acceptance Criteria として作業開始前に明文化する
2. すべての成果物(コード・文書・データ・生成コンテンツ)は作成者以外のレビューを経て承認する
3. AI生成物も人間の成果物と同一の品質基準で扱い、自動承認しない
4. 不具合・差戻しは記録し、傾向を[継続的改善](continuous-improvement.md)へ入力する

## 品質基準

| 対象 | 基準 |
| --- | --- |
| コード | Ruff / Mypy(strict)/ Pytest がすべて成功、CI green |
| 文書 | レビューで内容確認済み、更新履歴が追跡可能 |
| 学習データ | スキーマ準拠、出典記録あり、著作権確認済み |
| 生成コンテンツ | 問題・正解・解説の整合、読み上げの自然さ、正確性の人間確認 |

## 検証の仕組み

- CI による自動検証(lint、型、テスト、スキーマ、ログ形式)
- PR テンプレートのレビューチェックリスト
- コンテンツ固有のレビュー([content-review-checklist](../templates/content-review-checklist.md))

## 記録

品質に関する記録(テスト結果・レビュー結果・差戻し)は PR・Issue・`reports/quality/` に保持し、
[監査証跡](audit-trail.md)の対象とする。
