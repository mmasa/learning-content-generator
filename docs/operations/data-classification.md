# データ分類(Data Classification)

## 分類

| 分類 | 定義 | 例 | Git | AIサービス送信 |
| --- | --- | --- | --- | --- |
| Public | 公開可能 | 公開ドキュメント、架空サンプル問題 | 可 | 可 |
| Internal | 内部限定 | 運用ログ、集計レポート、設計文書 | 可 | 可(内容を確認の上) |
| Confidential | 秘密 | 契約資料、ライセンス未確認教材、未確認の試験問題・規格本文 | **不可** | **不可** |
| Restricted | 厳秘 | APIキー、トークン、パスワード、個人情報、TTS/LLM認証情報 | **不可** | **不可** |

## 運用

- Issue には Data Classification 欄で扱うデータの分類を記載する
- コンテンツは `contents/<name>/config/content.yaml` の `data_classification` で既定分類を設定し、
  ファイル単位で異なる場合はメタデータ(出典記録等)に明記する
- 分類に迷う場合は上位(より厳しい)分類として扱う

## コミット禁止(再掲)

APIキー / アクセストークン / パスワード / 個人情報 / 契約上非公開の資料 /
ライセンス上再配布できない教材 / 未確認の試験問題全文 / 未確認の規格本文 /
有償資料の複製 / 音声生成サービスの認証情報

`contents/*/raw/` と `contents/*/audio/` は `.gitignore` で除外済み。
Confidential 以上のデータはローカルまたは別途のアクセス制御された保管場所で扱う。
